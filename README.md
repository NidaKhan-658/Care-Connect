# CareConnect: Patient Engagement Feature Backlog

**Role:** Business Analyst / Product Owner (simulated project)

## The Problem
Healthcare providers lose significant revenue and, more importantly, 
compromise patient outcomes due to missed appointments and poor medication 
adherence. Existing reminder systems are inconsistent, and patients lack a 
simple, secure way to communicate with their care team between visits.

## My Approach
I worked through this as an end-to-end BA/Product Owner exercise, covering 
the full lifecycle from discovery to sprint execution:

1. **Discovery** — Defined the business problem, mapped stakeholders, 
   and built patient/staff personas
2. **Backlog** — Structured 3 epics into features and 13 user stories with 
   Gherkin acceptance criteria, then prioritized using MoSCoW
3. **Compliance** — Documented HIPAA considerations and non-functional 
   requirements upfront, not as an afterthought
4. **Design** — Created low-fidelity wireframes for the three core screens : https://www.figma.com/design/c4SUyWb44QKEAFqoxEUsuV/CareConnect-Wireframes?node-id=0-1&t=7wJO2x1AvYSwHcHv-1
5. **Sprint Simulation** — Ran a 2-sprint mock execution with sprint 
   reviews and retrospectives
6. **Outcome Metrics** — Defined how success would actually be measured 
   post-launch

## Projected Outcome
Based on industry benchmarks for SMS-based reminder systems, this feature set 
is projected to reduce appointment no-shows by 15% and increase medication 
adherence logging by 25% within the first 3 months post-launch.

## Tools Used
- **Backlog & documentation:** Markdown, CSV
- **Design:** Figma
- **Version control:** Git / GitHub

## What This Project Demonstrates
- Translating a business problem into a structured, prioritized backlog
- Writing testable acceptance criteria (Gherkin format)
- Thinking through compliance and non-functional requirements proactively, 
  not reactively
- Running a full Agile sprint cadence, including retrospectives that fed 
  process improvements back into the next sprint
- Defining measurable success criteria tied back to the original business case
