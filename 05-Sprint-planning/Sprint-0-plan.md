# Sprint 0 Plan: CareConnect

## Purpose of Sprint 0
Sprint 0 is a preparation sprint — no user-facing features are shipped. 
The goal is to set up the team, environment, and backlog so Sprint 1 can 
start building immediately.

## Team Setup
- **Product Owner:** Responsible for backlog prioritization and acceptance criteria sign-off
- **Scrum Master:** Facilitates ceremonies, removes blockers
- **Development Team:** 2 backend engineers, 2 frontend engineers, 1 QA engineer
- **Stakeholder liaison:** Compliance representative (attends sprint reviews for 
  HIPAA-sensitive stories)

## Sprint 0 Activities
1. **Backlog refinement** — Review all epics/features/stories from Phase 2; 
   confirm acceptance criteria are clear and testable
2. **Environment setup** — Dev, staging, and production environments configured; 
   CI/CD pipeline established
3. **Technical spikes** — Investigate SMS gateway vendor options (must support 
   HIPAA-compliant BAA); investigate push notification service
4. **Definition of Ready / Definition of Done** — Agreed and documented (see 
   dor-dod.md)
5. **Initial velocity estimate** — Since this is a new team, we'll assume a 
   conservative starting velocity of 20 points per 2-week sprint, to be 
   recalibrated after Sprint 1

## Sprint 0 Deliverables
- Refined, estimated backlog (carried over from Phase 2)
- Confirmed team roles and ceremony cadence (daily standup, sprint planning, 
  sprint review, retrospective)
- Environments ready for development
- Vendor decision for SMS gateway (with signed BAA in progress)

## Sprint Cadence Going Forward
- Sprint length: 2 weeks
- Daily standup: 15 minutes, same time each day
- Sprint planning: first day of sprint, 1 hour
- Sprint review: last day of sprint, 30 minutes (demo to stakeholders)
- Retrospective: last day of sprint, 30 minutes (team only)
